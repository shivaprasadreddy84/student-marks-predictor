# MarkSense

## ML-Based Student Marks Prediction

MarkSense is a student performance prediction system that uses
academic factors and exam difficulty to predict student marks.

The project is being developed as a team project using Machine
Learning, Statistics, Web Development, and Database technologies.

---

## Project Objective

The main objective of MarkSense is to predict a student's expected
marks based on factors such as:

- Previous marks
- Assessment marks
- Attendance
- Study hours
- Exam difficulty

The system will also provide performance analysis and prediction
history.

## Planned Backend

The backend will be developed using:

- Python
- Flask
- REST APIs

The backend will handle:

- User registration
- Login
- Student and Admin access
- Student data
- Exam data
- Prediction requests
- Database communication

---

## Planned Database

The database will store:

- User details
- Student details
- Exam details
- Previous marks
- Assessment marks
- Attendance
- Study hours
- Prediction records
- Performance records

---

## Machine Learning

The temporary frontend prediction formula will later be
replaced with a trained Machine Learning model.

The initial model planned for the project is:

**Linear Regression**

The model will learn from student academic data and predict
expected marks.

---

## Statistical Analysis

The system will use statistical methods such as:

- Mean
- Median
- Standard Deviation
- Minimum and Maximum
- Percentage
- Correlation
- Graphical Analysis

These methods will help analyze student performance and
academic factors.
